Stages

Click a stage, to see the details

Creating Dataset
Prepare source data and manifestsView docs →
dataset:
  train:
    - data_src: librispeech_100/esp2_asr
      data_src_args:
        split: train-clean-100
  valid:
    - data_src: librispeech_100/esp2_asr
      data_src_args:
        split: dev-clean
Train Tokenizer
ASR-specific declared stageView docs →
tokenizer:
  model_type: bpe
  vocab_size: 30
  save_path: ${data_dir}/bpe_30
Collect Stats
Feature statistics and shape collectionView docs →
No configuration required
Training
Training model loss protocol and Lightning settingsView docs →
task: espnet3.systems.esp2_asr.task.ASRTask
model:
  encoder: transformer
  decoder: transformer
  model_conf:
    ctc_weight: 0.3
Inference
Checked audio inputs and named text outputsView docs →
dataset:
  test:
    - name: eval1
      data_src: librispeech_100/esp2_asr
      data_src_args:
        split: test-clean
    - name: eval2
      data_src: librispeech_100/esp2_asr
      data_src_args:
        split: test-other
Metrics
Bind metric contract inputs to artifacts or dataset columnsView docs →
metrics:
  - metric:
      _target_: espnet3.systems.esp2_asr.metrics.wer.WER
    inputs:
      ref: dataset:text
      hyp: text
Publication
Pack local artifacts; uploading is explicitView docs →
pack_model:
  out_dir: ${exp_dir}/model_pack
  include:
    - src
    - dataset
  exclude:
    - last.ckpt
Demo
UI fields derive from packed inference contractView docs →
model:
  dir_or_tag: exp/${exp_tag}/model_pack
  device: auto
ui:
  app_script: ${config_path:../src/app.py}
  title: ASR demo
